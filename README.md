# Aisha's Enchanted Invite

Qiz bola tug'ilgan kuni uchun taklifnoma sahifasi (React + TS + Tailwind + Vite).

MA'LUMOTLAR:

- Bayram egasi: Oisha, 4 yosh

- Sana: 2027-yil 3-fevral

- Joy: Sxovat savdo markazi, 3-qavat, bolalar maydonchasi

- Manzil xaritasi: Google Maps link tugmasi (havolani men keyin qo'yaman)

- Fon musiqa: YouTube audio (mute holda avtoplay, pastda play/pause tugma)

DIZAYN:

- Fon: ertak-malika uslubidagi umumiy grafika (qasr, yulduzlar, sehrli o'rmon, tojlar, sharlar) — pushti-binafsha-oltin rang gradienti, brendlangan multfilm qahramonlarisiz

- Sekin harakatlanuvchi zarralar: yulduzchalar, konfetti, gul barglari

- Shrift: yumaloq, bolalarcha, ertak uslubida

- Glassmorphism kartalar matn uchun

BO'LIMLAR:

1. Hero: "Oisha 4 yoshga to'ldi!" + countdown timer (2027-02-03 gacha)

2. Sana/joy kartasi + "Xaritada ko'rish" tugmasi

3. Foto galereya (Oishaning suratlari uchun joy)

4. RSVP forma: ism, keladi/kelmaydi, mehmonlar soni, tabrik xati — Supabase "rsvps" jadvaliga yozilsin

5. Til almashtirish: UZ/RU/EN tugmasi

6. Kalit ikonkasi (🔑) — bosilganda parol so'raydi (1317), to'g'ri bo'lsa RSVP ro'yxati (jami tasdiqlagan + mehmonlar soni) ko'rinadi

TEXNIK: mobil-responsive, tez yuklanadigan, animatsiyalar silliq.
